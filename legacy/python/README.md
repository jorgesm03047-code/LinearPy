# Versión anterior en Python

Este directorio preserva la aplicación de Streamlit como referencia histórica. La aplicación web actual se ejecuta desde la raíz con Node.js y no requiere estas dependencias.

Para estudiar esta versión de forma independiente, crea un entorno Python e instala `requirements.txt` de este directorio. Después ejecuta `streamlit run main.py` desde aquí. Sus procedimientos y estilos no forman parte del rediseño web.
